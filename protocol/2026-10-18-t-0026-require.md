## What changed

- `internal/pack`:
  - `lib/<name>.lua` files are loaded into `Pack.Modules`.
  - They have the same size and lint rules as scripts, and there are at most 100 of them.
  - Nothing but plain module files may be in `lib/`.
  - Scripts and modules must be plain files, not links.
- `internal/script/require.go`:
  - `require(name)` runs a module at most once per instance, with that instance's globals and within the running call's budgets, and caches the result.
  - A missing module, an error in a module, and a cycle within one hook are script errors.
  - What modules return counts toward the instance's memory.
- `internal/game`: modules are compiled at world start, before the room scripts.
- The test pack's cellar uses `lib/visits.lua`, so the Playwright tests run a module.
- Docs: `docs/content-format.md` and `docs/lua-sandbox.md`.

| Severity | Finding | Fix |

| Medium | The error for a missing module copied the whole name in twice. Feeding the error back into `require` grew it past 1 MiB, in Go, and one call allocated about 88 MiB against the 32 MiB limit | A name that is not a module name gets a short error, with the name cut to 64 bytes. `TestRequireErrorStaysSmall` |
