## Goal

In edu mode, a setting lets GMs (teachers) load a pack a player (a kid) made in the editor and run it as a world for their class, after looking at it.

## Acceptance

- [ ] An admin setting turns it on; off by default
- [ ] A GM sees the pack's texts and pictures before any player can join; the same limits and checks as an admin upload (T-0040)
- [ ] Edu rules stay: invite only, no free chat, the world is private
- [ ] Docs in docs/accounts.md; tests, test-engineer and security-reviewer runs
